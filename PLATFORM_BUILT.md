## **🎨 CUSTOMIZATION:**

### **Change Sample Data:**

### **Add Real TED API:**
1. Get API key: https://developer.ted.europa.eu
2. Uncomment line 40 in `ted_eu.py`
3. Add `TED_API_KEY` to environment

Edit `app.py` and `dashboards/generator.py`
