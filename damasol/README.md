# Damasol Limited — Real Estate Opportunity Engine

Δύο πράγματα, ένα πακέτο:

1. **`damasol.screener`** — σαρώνει αγγελίες ακινήτων με σκληρά φίλτρα (π.χ.
   *όλη η Ελλάδα, αγορά, έως 50.000 €*), βαθμολογεί κάθε ακίνητο ως προς το πόσο
   καλή **επαγγελματική ευκαιρία** είναι, και βγάζει καταταγμένη λίστα σε
   CSV / JSON / HTML.
2. **`damasol.brokers` + `damasol.outreach`** — χτίζει κατάλογο επαγγελματιών
   ακινήτων της Ελλάδας και παράγει την καμπάνια επικοινωνίας της Damasol
   (email / SMS / Viber / LinkedIn), προσωποποιημένη ανά παραλήπτη.

3. **`damasol.valuation` + `damasol.strategies` + `damasol.analyse`** — για ένα
   συγκεκριμένο ακίνητο: πόσο αξίζει τώρα, πόσο σε ορίζοντα, και ποιος τρόπος
   αξιοποίησης αποδίδει περισσότερα με λιγότερο κόπο και λιγότερο κεφάλαιο.
4. **`damasol.signals`** — τι λέει ο έξω κόσμος για την περιοχή: τουριστικές
   ροές, δημόσια έργα, ειδήσεις ανάπτυξης.
5. **`damasol.registry`** — δύο μητρώα: οι **ιδέες** σημάτων και οι
   **υλοποιημένοι μηχανισμοί**, με έλεγχο συνέπειας μεταξύ τους και με τον κώδικα.

Μόνο stdlib. Τρέχει σε σκέτο Python 3.9+ χωρίς `pip install`.
(Εξαιρέσεις: ο adapter του Spitogatos θέλει `playwright`, τα μητρώα θέλουν `pyyaml`.)

## Γρήγορη εκκίνηση

```bash
# 1) ΟΛΗ Η ΕΛΛΑΔΑ, ΟΛΟΙ ΟΙ ΤΥΠΟΙ — μία εντολή
python -m damasol.screener \
    --sources spitogatos --all-types \
    --max-price 50000 --min-price 5000 \
    --enrich-top 150 --top 500 \
    --out out/eukairies --html-out out/apotelesmata.html

# 1β) Ή από δικό σας αρχείο, χωρίς καμία σάρωση
python -m damasol.screener --sources csv --csv-path akinita.csv --all-types \
    --max-price 50000 --out out/eukairies

# 1γ) Ή και τα δύο μαζί — συγχωνεύονται και αποδιπλασιάζονται
python -m damasol.screener --sources spitogatos,csv --csv-path akinita.csv --all-types

# 2) Ο κατάλογος μεσιτών (μόνο μεσιτικά γραφεία, με emails)
python -m damasol.brokers \
    --categories "Μεσιτικό γραφείο" \
    --with-contacts --contactable-only \
    --out out/brokers

# 3) Η καμπάνια — παράγει αρχεία, ΔΕΝ στέλνει τίποτα
python -m damasol.outreach.merge \
    --brokers out/brokers.csv --channel email \
    --sender-name "Ονοματεπώνυμο" --sender-title "Investment Director" \
    --reply-email deals@damasol.com --phone "+30 ..." \
    --out out/campaign
```

```bash
# 4) Πλήρης ανάλυση ενός ακινήτου από τη λίστα
python -m damasol.analyse --from-json out/eukairies.json --rank 1

# 5) Τα μητρώα ιδεών και μηχανισμών
python -m damasol.registry audit
python -m damasol.registry list ideas --status idea
python -m damasol.registry add-idea --title "..." --hypothesis "..."
```

Δείτε τα presets στο `config.yml` για έτοιμους συνδυασμούς παραμέτρων.

## Πηγές και robots.txt — διαβάστε το πριν τρέξετε σάρωση

Το πακέτο σέβεται το `robots.txt` κάθε πηγής **εξ ορισμού**, και πλέον διαβάζει
και τους κανόνες που **απευθύνονται σε εμάς ονομαστικά** (`ClaudeBot`,
`Claude-User`, `Claude-Web`). Ομάδα που μας ονομάζει υπερισχύει της ομάδας `*`
προς τις δύο κατευθύνσεις. Η εικόνα σήμερα:

| Πηγή | Τι λέει για εμάς | Τεχνική πρόσβαση |
|---|---|---|
| **spitogatos.gr** | ⚠️ robots.txt: επιτρέπει, δεν μας ονομάζει. **Όροι Χρήσης άρθρο 2: αποθήκευση μόνο για προσωπική χρήση, «by no means for commercial use»** → απαιτείται γραπτή άδεια | Πίσω από σύστημα ανίχνευσης bot → **απαιτεί πραγματικό browser** |
| **xe.gr** | ❌ `ClaudeBot`/`Claude-Web`: `Disallow: /` · `Claude-User`: στενή λίστα που **δεν** περιλαμβάνει ούτε `/property/results` ούτε `/property/pros` | Δουλεύει με απλό HTTP |
| **remax.gr** | ❌ `User-agent: ClaudeBot` → `Disallow: /` σε όλο τον ιστότοπο | Δουλεύει με απλό HTTP |
| eauction.gr | ❌ `Disallow: /` | — |
| **αρχείο CSV** | ✅ Δικά σας δεδομένα, κανένας περιορισμός | Πάντα |

**Το robots.txt δεν είναι η σύμβαση.** Είναι η πολιτική μιας πύλης για crawlers·
οι Όροι Χρήσης είναι η σύμβαση, και όταν διαφωνούν υπερισχύει η σύμβαση. Το
Spitogatos το δείχνει καθαρά: το robots.txt του επιτρέπει τις σελίδες
αναζήτησης, αλλά το άρθρο 2 των Όρων επιτρέπει ηλεκτρονική αποθήκευση
*«for personal use, but by no means for commercial use»*. Σάρωση για λογαριασμό
επενδυτικού οργανισμού είναι εμπορική χρήση.

Γι' αυτό οι πηγές δηλώνουν `requires_consent` και **ο screener αρνείται να
τρέξει** με εξήγηση, αντί να το κάνει σιωπηλά. Με γραπτή άδεια:
`--i-have-written-consent`.

Δύο ακόμη πράγματα, καθαρά:
- Το xe.gr και το remax.gr **μας απαγορεύουν ονομαστικά**. Το ότι απαντούν σε
  απλό HTTP δεν αλλάζει τι έχουν δηλώσει. Το πακέτο δεν αλλάζει User-Agent για
  να τα παρακάμψει και δεν πρέπει να το κάνετε ούτε εσείς χωρίς δική τους άδεια
  ή εμπορική συμφωνία.

Ο **κατάλογος μεσιτών** του xe.gr (`/property/pros`) που χρησιμοποιήθηκε νωρίτερα
εμπίπτει στην απαγόρευση του `Claude-User` — για την καμπάνια χρησιμοποιήστε
ΓΕΜΗ, επιμελητήρια ή συλλόγους μεσιτών (βλ. `outreach/COMPLIANCE_GDPR.md`).

Πρακτικά:

- **Για τον screener, η καθαρή διαδρομή είναι το Spitogatos.** Το `robots.txt`
  του επιτρέπει τις σελίδες αναζήτησης· χρειάζεται όμως browser για να περάσει
  το bot protection: `pip install playwright && playwright install chromium`.
- **Ο adapter του xe.gr υπάρχει και είναι πλήρως λειτουργικός, αλλά αρνείται να
  τρέξει** επειδή το `robots.txt` του xe.gr απαγορεύει ρητά τη σάρωση των
  αποτελεσμάτων. Υπάρχει σημαία `--ignore-robots`, αλλά η χρήση της είναι δική
  σας εμπορική και νομική απόφαση και υπόκειται στους Όρους Χρήσης του xe.gr.
  Αν χρειάζεστε τα δεδομένα σε συνεχή βάση, το σωστό είναι εμπορική συμφωνία
  παροχής δεδομένων με την πύλη.
- **Ο κατάλογος μεσιτών του xe.gr είναι επιτρεπτός** και είναι η πηγή του
  `damasol.brokers`.

Ελέγξτε μόνοι σας οποιοδήποτε URL:

```python
from damasol.http import PoliteFetcher
print(PoliteFetcher()._robots.explain("https://www.spitogatos.gr/pwliseis-katoikies/ellada"))
```

## Η διαλογή — ποια ακίνητα αξίζουν πλήρη ανάλυση

**Αυτό δεν είναι ετυμηγορία.** Είναι φθηνή διαλογή που κατατάσσει χιλιάδες
υποψήφιους ώστε να ανέβουν τα λίγες εκατοντάδες που αξίζουν την ακριβή ανάλυση.
Η ετυμηγορία βγαίνει μετά, από την απόδοση κάθε πλάνου υπό πίεση.

| Άξονας | Βάρος | Τι μετράει |
|---|---|---|
| **Εκτιμώμενη απόδοση** | 30% | Μεικτή απόδοση από τοπικά συγκριτικά **ενοικίων** |
| **Τιμή έναντι αγοράς** | 20% | €/τ.μ. έναντι της διαμέσου της γειτονιάς — *υποβιβασμένο, βλ. παρακάτω* |
| **Ρευστότητα αγοράς** | 15% | Βάθος αγοράς, απόσταση από αστικό κέντρο, πλήθος συγκρίσιμων |
| **Καταλληλότητα εισιτηρίου** | 15% | Αφήνει η τιμή περιθώριο για φόρους, έξοδα, ανακαίνιση; |
| **Περιθώριο υπεραξίας** | 15% | Κατάσταση, έτος κατασκευής, ενδείξεις ανακαίνισης/αλλαγής χρήσης |
| **Χρόνος στην αγορά** | 5% | Νέα αγγελία = πλεονέκτημα· πολύ παλιά = διαπραγματευτικό περιθώριο |

Τα βάρη αλλάζουν με `--weights '{"rental_yield":0.40, ...}'`.

### Από πού έρχονται τα συγκριτικά

Με σειρά προτεραιότητας, το πρώτο επίπεδο που έχει τουλάχιστον 4 συγκρίσιμα:

1. **Γειτονιά** — η ίδια συμβολοσειρά περιοχής που δημοσιεύει η πύλη
   (π.χ. `Θεσσαλονίκη (Ξηροκρήνη)`).
2. **Κελί ~2,2 χλμ** — γεωγραφικό, για αγγελίες χωρίς αντιστοιχία γειτονιάς.
3. **Δήμος** — τελευταία εφεδρεία.

Η γειτονιά προηγείται για συγκεκριμένο λόγο: σε ένα κελί 5 χλμ στο κέντρο της
Θεσσαλονίκης οι τιμές διαφέρουν κατά τρεις φορές, οπότε η σύγκριση με τον μέσο
όρο του κελιού «ανακαλύπτει» εκπτώσεις 70% που δεν υπάρχουν. Η διάμεσος
υπολογίζεται **με περικοπή των άκρων** (winsorized) ώστε μία λανθασμένη
καταχώρηση να μη μετακινεί τη βάση σύγκρισης.

### Η εκτίμηση ενοικίου παίρνει «κούρεμα»

Ένα διαμέρισμα που πωλείται στο ένα πέμπτο της τιμής του δρόμου του είναι φθηνό
για λόγους — κατάσταση, όροφος, διαρρύθμιση, νομική εικόνα — που πλήττουν και το
ενοίκιο. Το να υποτεθεί ότι πιάνει το διάμεσο ενοίκιο της γειτονιάς είναι που
κατασκευάζει αποδόσεις 20% που δεν υπάρχουν.

Η εκτίμηση ενοικίου μειώνεται αναλογικά με τη θέση της τιμής του ακινήτου
έναντι της γειτονιάς, με δάπεδο στο 60%:

```
εκτ. ενοίκιο/τ.μ. = ενοίκιο γειτονιάς/τ.μ. × (0,5 + 0,5 × τιμή_ακινήτου/τιμή_γειτονιάς)
```

Το ποσοστό της μείωσης αναγράφεται ρητά στην τεκμηρίωση κάθε ακινήτου.

### Οροφές αληθοφάνειας

Πάνω από **55% έκπτωση** ή **14% μεικτή απόδοση**, ο αριθμός είναι πολύ πιο
πιθανό να οφείλεται σε αναντιστοιχία συγκριτικών ή σε νομικό ιδιαίτερο
(ποσοστό συνιδιοκτησίας, ψιλή κυριότητα) παρά σε πραγματική ευκαιρία. Η
βαθμολογία **σταματά να αυξάνεται** πέρα από αυτά τα όρια, το ακίνητο δέχεται
μικρή ποινή και σημαίνεται για χειροκίνητο έλεγχο, αντί να ανέβει στην κορυφή
της λίστας.

Κάθε ακίνητο συνοδεύεται από **τεκμηρίωση στα ελληνικά** (γιατί βαθμολογήθηκε
έτσι) και από **σημεία ελέγχου** — αυτόματες προειδοποιήσεις για ψιλή κυριότητα,
ποσοστά συνιδιοκτησίας, πλειστηριασμούς, παλαιά κτίσματα, αρτιότητα οικοπέδων.

### Ο αγωγός σε τέσσερα βήματα

1. **Συλλογή** όλων των αγγελιών που περνούν τα σκληρά φίλτρα.
2. **Προκαταρκτική βαθμολόγηση** με συγκριτικά *μέσα από το ίδιο το δείγμα* —
   δωρεάν, χωρίς επιπλέον αιτήματα.
3. **Εμπλουτισμός μόνο των κορυφαίων N**: για κάθε κελί περιοχής όπου βρίσκονται,
   τραβιέται η **πραγματική τοπική αγορά χωρίς όριο τιμής** (3 σελίδες) και η
   **τοπική αγορά ενοικίων** (2 σελίδες). Εδώ το «φθηνό» γίνεται «φθηνό σε σχέση
   με τη γειτονιά του, με απόδοση Χ%». Οι ίδιοι οι υποψήφιοι εξαιρούνται από τη
   βάση σύγκρισής τους, ώστε να μην τραβούν τη διάμεσο προς τα κάτω.
4. **Τιμολόγηση κάθε πλάνου** για κάθε ακίνητο της shortlist — αποτίμηση,
   32 πλάνα, δοκιμή αντοχής.
5. **Κατάταξη στην απόδοση** και εξαγωγή. Ακίνητα χωρίς κανένα εφικτό πλάνο
   εξαιρούνται, όσο φθηνά κι αν φαίνονται.

Το βήμα 3 είναι το ακριβό, γι' αυτό τρέχει σε shortlist. Όλα cache-άρονται στον
δίσκο: η δεύτερη εκτέλεση δεν κοστίζει αιτήματα.

## Αξία μεταπώλησης — τώρα και αργότερα

Η μέθοδος είναι αυτή που χρησιμοποιεί κάθε εκτιμητής — σύγκριση με το τοπικό
απόθεμα — αλλά γραμμένη ώστε να φαίνεται. Ξεκινά από τη διάμεσο €/τ.μ. της
γειτονιάς και εφαρμόζει **ονομαστικούς πολλαπλασιαστές** για ό,τι κάνει αυτό το
ακίνητο να διαφέρει από το τυπικό:

| Συντελεστής | Εύρος | Πηγή |
|---|---|---|
| Κατάσταση | −32% (ημιτελές) ως +24% (νεόδμητο) | κείμενο αγγελίας |
| Όροφος | −28% (υπόγειο) ως +7% (ρετιρέ)· −16% επιπλέον χωρίς ανελκυστήρα | κείμενο |
| Παλαιότητα | −13% (>45 ετών) ως +12% (<5 ετών) | έτος κατασκευής |
| Μέγεθος | −11% (>160 τ.μ.) ως +12% (<30 τ.μ.) | εμβαδόν |
| Ενεργειακή κλάση | −8% (G) ως +6% (A+) | κείμενο |
| Νομική κατάσταση | −45% (ποσοστό) ως 0% (καθαροί τίτλοι) | κείμενο |

Κάθε γραμμή τυπώνεται με την τιμή της, την αιτιολογία της, και **αν προέκυψε από
δεδομένο ή από παραδοχή**. Εκεί απαντιέται το «να βρούμε σωστούς παράγοντες»:
δεν κρύβεται τίποτα σε έναν συντελεστή-μπαλαντέρ, οπότε κάθε γραμμή μπορεί να
αμφισβητηθεί και να βαθμονομηθεί χωριστά.

Βγαίνουν τρεις αριθμοί:

- **Άμεση** — ρευστοποίηση σε εβδομάδες. Έκπτωση 1–17% ανάλογα με τη ρευστότητα
  της περιοχής: όπου το απόθεμα κάθεται, η ταχύτητα κοστίζει περισσότερο.
- **Ανοιχτής αγοράς** — κανονική περίοδος διάθεσης, **με εύρος εμπιστοσύνης**.
- **Σε ορίζοντα** — 12/24/36 μήνες, προαιρετικά μετά από εργασίες.

Το εύρος δεν είναι διακοσμητικό: πλαταίνει με λίγα συγκριτικά, με διεσπαρμένα
συγκριτικά, και με **κάθε παράγοντα που χρειάστηκε να μαντέψουμε**. Αποτίμηση
πάνω σε τρεις αγγελίες και έξι παραδοχές το δηλώνει, αντί να παριστάνει τον αριθμό.

> **Η μεγαλύτερη παραδοχή:** η βάση είναι **ζητούμενες** τιμές, κουρεμένες 7%
> για να προσεγγίσουν τιμές συναλλαγής. Το 7% το μαντέψαμε. Μόλις έχετε 20 δικά
> σας κλεισμένα deals, αντικαταστήστε το με μέτρηση — είναι η εγγραφή SIG-015
> στο μητρώο ιδεών και η σημαντικότερη της λίστας.

## Η κατάταξη γίνεται στην απόδοση, όχι στην έκπτωση

Η πρώτη έκδοση κατέτασσε με βάση το πόσο κάτω από τις **ζητούμενες** τιμές των
γειτόνων ήταν μια αγγελία, με βάρος 35%. Αυτό ήταν λάθος άξονας: ζητούμενη τιμή
είναι γνώμη πωλητή, όχι γεγονός, και μια «έκπτωση 60%» είναι εξίσου πιθανό να
σημαίνει ότι οι γείτονες ονειρεύονται.

Τώρα:

| | Πριν | Τώρα |
|---|---|---|
| Ρόλος της έκπτωσης | κατέτασσε τη λίστα (35%) | **μόνο διαλογή** (20%), δεν κρίνει τίποτα |
| Τι κατατάσσει | βαθμός ευκαιρίας | **απόδοση υπό πίεση** από συγκεκριμένο πλάνο |
| Ευθραυστότητα | αόρατη | **δικός της δείκτης** (βεβαιότητα) |

Η διαλογή αποφασίζει μόνο ποια ακίνητα αξίζουν την ακριβή ανάλυση. Η ετυμηγορία
βγαίνει από το τι αποδίδει πραγματικά κάποιο πλάνο.

### Η δοκιμή αντοχής

Κάθε πλάνο τιμολογείται δύο φορές: κανονικά, και ξανά υποθέτοντας ότι **τα
δεδομένα της πύλης μάς κολάκευαν** — συγκριτικά πώλησης 20% αισιόδοξα, ενοίκια
15%. Ό,τι επιβιώνει είναι ο τίμιος αριθμός, και η διαφορά των δύο **είναι** η
ευθραυστότητα.

Στο ίδιο διαμέρισμα 40.000 €:

| Πλάνο | Ονομαστικό ROI | Υπό πίεση | Βεβαιότητα |
|---|---|---|---|
| Αγορά → πώληση | 62,1% | **10,1%** | 25/100 |
| Αγορά → ελαφριά ανακαίνιση → πώληση | 36,7% | **1,2%** | 18/100 |
| Αγορά → μακροχρόνια μίσθωση (10 έτη) | 7,6% | **4,9%** | 43/100 |

Η μεταπώληση χάνει σχεδόν όλο το κέρδος της, γιατί όλο το περιθώριό της *είναι*
τα συγκριτικά. Η μίσθωση συνεχίζει να εισπράττει και μπορεί απλώς να περιμένει.
Ο δείκτης απόδοσης σταθμίζει **65% την υπό πίεση** και 35% την ονομαστική, ώστε
ένα πλάνο που καταρρέει να μην κατατάσσεται πρώτο επειδή η βιτρίνα του λάμπει.

## Έξι ξεχωριστοί δείκτες, και ένας συνδυαστικός

Όλοι σε **απόλυτη κλίμακα** 0–100, ώστε αριθμοί από διαφορετικά ακίνητα να
συγκρίνονται μεταξύ τους.

| Δείκτης | Τι μετράει | Προεπιλεγμένο βάρος |
|---|---|---|
| **Απόδοση** | Ετησιοποιημένο ROI, σταθμισμένο προς την υπό πίεση εκδοχή | 35% |
| **Βεβαιότητα** | Πόσο κέρδος επιβιώνει αν τα δεδομένα ήταν ψέμα | 20% |
| **Ταχύτητα** | Πότε γυρίζουν τα λεφτά — πρώτη ροή και τελική έξοδος | 15% |
| **Κεφάλαιο** | Πόσο λίγα χρειάζονται για να ξεκινήσεις | 15% |
| **Ευκολία** | Πόσο λίγη προσοχή τρώει | 10% |
| **Ασφάλεια** | Πόσο άσχημα πάει αν το πλάνο είναι λάθος | 5% |

Αναφέρονται **και ξεχωριστά και συνδυαστικά**: η έξοδος δίνει νικητή σε κάθε
άξονα χωριστά, νικητή ανά κατηγορία, και συνολικό νικητή. Ένα πλάνο με 85 στην
απόδοση και 25 στη βεβαιότητα το λέει καθαρά, αντί να γίνει ένα βολικό 55 που
δεν σημαίνει τίποτα.

```bash
--w-return 0.5 --w-certainty 0.3 --w-capital 0.2    # επιθετικό αλλά προσεκτικό
--w-certainty 0.6 --w-return 0.2                    # μόνο ό,τι αντέχει
--w-capital 0.6 --w-speed 0.3                       # πολλά μικρά, γρήγορα deals
```

## Τα πλάνα: απόκτηση × μετασχηματισμός × έξοδος

Δεν υπάρχει χειρόγραφη λίστα στρατηγικών. Τα πλάνα παράγονται ως πίνακας, οπότε
τίποτα δεν λείπει επειδή δεν το σκέφτηκε κανείς:

```
ΑΠΟΚΤΗΣΗ    κτίσμα │ οικόπεδο/αγροτεμάχιο │ αντιπαροχή
    ×
ΜΕΤΑΣΧΗΜ.   τίποτα │ ελαφριά │ πλήρης │ ριζική ανακαίνιση │ ανέγερση
    ×
ΕΞΟΔΟΣ      πώληση │ μακροχρόνια │ βραχυχρόνια │ φοιτητική │ επαγγελματική
            μίσθωση │ λειτουργία επιχείρησης │ διακράτηση
```

**32 πλάνα** για ένα διαμέρισμα, **10** για οικόπεδο. Μέσα σε αυτά υπάρχουν
αυτούσια όλα όσα ζητήσατε: αγορά οικοπέδου → ανέγερση → πώληση, → μίσθωση,
→ επαγγελματική εκμετάλλευση, → λειτουργία επιχείρησης· και αγορά → ανακαίνιση
→ πώληση ή μίσθωση ή αλλαγή χρήσης. Η μακροχρόνια μίσθωση προσφέρεται σε τρεις
ορίζοντες (3/5/10 έτη) γιατί ο ορίζοντας αλλάζει και την απόδοση και τη
βεβαιότητα.

Όσα δεν γίνονται **δηλώνουν γιατί** αντί να παίρνουν μηδέν.

### Δύο αγορές, όχι μία

Ένα οικόπεδο και το κτίριο που θα σταθεί πάνω του είναι εντελώς διαφορετικές
αγορές: γη με δεκάδες ευρώ το τετραγωνικό, διαμερίσματα με χιλιάδες. Η πρώτη
έκδοση τιμολογούσε την ανέγερση με το €/τ.μ. **του οικοπέδου** και έβγαζε −70%
απόδοση σε κάθε πλάνο ανέγερσης — σφάλμα που έμοιαζε με συμπέρασμα. Τώρα η
ανέγερση απαιτεί ρητά τιμή δομημένου χώρου (`--built-per-sqm`) και μίσθωμα
δομημένου χώρου (`--rent-per-sqm`)· χωρίς αυτά δηλώνεται μη εφικτή αντί να
μαντεύεται. Ο screener τα αντλεί μόνος του από τα οικιστικά συγκριτικά του
κελιού.

Η δομήσιμη επιφάνεια, αν λείπει, εκτιμάται με συντελεστή 0,40 και **σημαίνεται
έντονα**: αγροτεμάχιο εκτός σχεδίου μπορεί να μην είναι δομήσιμο καθόλου.

### Δεν ανακαινίζει επειδή μπορεί

Κάθε επίπεδο εργασιών είναι δικό του πλάνο, οπότε η επιλογή γίνεται από την
κατάταξη και **φαίνονται και οι απορριφθείσες εναλλακτικές**. Στο ίδιο
διαμέρισμα 40.000 €, μίσθωση χωρίς έργα αποδίδει 15,0% ενώ με πλήρη ανακαίνιση
49.000 € αποδίδει 3,2%. Το μοντέλο δεν το απαγορεύει — απλώς το κατατάσσει εκεί
που ανήκει.

### Και δεν αγνοεί τα κόστη

Φόρος μεταβίβασης, συμβολαιογράφος, δικηγόρος, κτηματολόγιο, μεσιτικές, ΕΝΦΙΑ,
κοινόχρηστα, φόρος ενοικίου, τέλος ανθεκτικότητας, 15% απρόβλεπτα στα έργα. Σε
ακίνητο 45.000 € τα έξοδα κτήσης είναι **~9%** — τα σταθερά κόστη βαραίνουν
δυσανάλογα στα φθηνά ακίνητα. Όλα στο `costs.py`, μαζεμένα για να αμφισβητούνται.

## Σήματα: τι λέει ο έξω κόσμος

| Σήμα | Πηγή | Κατάσταση | Τι δίνει |
|---|---|---|---|
| **Τουριστικές ροές** | Eurostat `tour_occ_nin2` | ✅ ενεργό | Ένταση + ετήσιος ρυθμός ανά περιφέρεια |
| **Δημόσια έργα** | Διαύγεια opendata | ⚗️ πειραματικό | Ένταση αποφάσεων έργων ανά δήμο |
| **Ειδήσεις ανάπτυξης** | Δημόσιες ροές RSS | ⚗️ πειραματικό | Λίστα παρακολούθησης ανά περιοχή |

Δύο παγίδες που βρέθηκαν και διορθώθηκαν χτίζοντάς τα, γιατί δείχνουν τι είδους
λάθη κάνουν αυτά τα σήματα:

- **Τα 2020–2021 δεν είναι δεδομένα τουρισμού** — είναι δεδομένα κλειστών
  συνόρων. Αφελής ρυθμός με βάση το 2020 έδινε +40%/έτος για *κάθε* περιφέρεια.
  Εξαιρούνται. Ο πραγματικός ρυθμός είναι −1,8% ως +3,0%.
- **Λάθος αντιστοίχιση δήμου είναι χειρότερη από καμία.** Το «Ηράκλειο» ταίριαζε
  στον «Δήμο Ηράκλειας» Σερρών και η «Νέα Ερυθραία» στη «Νέα Ζίχνη». Τώρα, όταν
  ένα στέλεχος δείχνει σε δύο δήμους, το σύστημα **αρνείται να απαντήσει**.
  Σε 12 πόλεις: 8 σωστές, **0 λανθασμένες**, 4 χωρίς αντιστοίχιση.

## Τα δύο μητρώα

Ακριβώς αυτό που ζητήθηκε: ένα μέρος για τις **ιδέες**, ένα για τα **υλοποιημένα**.

**`registry/ideas.yml`** — 20 ιδέες σημάτων. Κάθε μία με **υπόθεση** (τι
πιστεύουμε και γιατί αυτό προβλέπει αξία), πηγή, εφικτότητα, αναμενόμενο όφελος
και κατάσταση. Ιδέα χωρίς υπόθεση δεν ελέγχεται ποτέ, οπότε η υπόθεση είναι
υποχρεωτική. Περιλαμβάνει και τις **απορριφθείσες**, με τον λόγο — ώστε να μην
ξαναπροταθούν σε έξι μήνες.

**`registry/mechanisms.yml`** — 20 μηχανισμοί που όντως τρέχουν, ο καθένας με
αρχείο, συνάρτηση, βάρος, **πώς επαληθεύτηκε** και **τι δεν ξέρει**.

Το `audit` είναι που τα κρατά ειλικρινή — 42 έλεγχοι:

```
$ python -m damasol.registry audit
✓ Τα μητρώα είναι συνεπή (20 ιδέες, 20 μηχανισμοί)
```

Ελέγχει ότι κάθε μηχανισμός δείχνει σε **αρχείο και συνάρτηση που υπάρχουν**,
ότι κάθε ιδέα σημειωμένη ως υλοποιημένη έχει πράγματι μηχανισμό, και — αυτό
πιάνει την πραγματική απόκλιση — ότι **τα βάρη στο μητρώο ταιριάζουν ακόμη με τα
βάρη στο `scoring.py`**. Τεκμηρίωση που μπορεί να αποδειχθεί λάθος είναι
τεκμηρίωση που αξίζει να διαβαστεί.

### Οι τέσσερις ιδέες με τη μεγαλύτερη απόδοση, αν μας δώσετε χρόνο

| id | Ιδέα | Γιατί |
|---|---|---|
| **SIG-015** | Πραγματικές τιμές συναλλαγών | Όλη η μηχανή στηρίζεται σε ζητούμενες τιμές. 20 δικά μας deals = βαθμονόμηση που δεν έχει κανείς |
| **SIG-008** | Αγγελίες που εξαφανίζονται γρήγορα | Ο καθαρότερος δείκτης ζήτησης, κοστίζει **μηδέν** εξωτερικά δεδομένα — μόνο να κρατάμε κάθε σάρωση |
| **SIG-003** | Δημογραφική τάση ανά δήμο | Το ισχυρότερο *αρνητικό* φίλτρο που λείπει· θα έκοβε μόνο του πολλές ψευδο-ευκαιρίες |
| **SIG-011** | Περιορισμοί βραχυχρόνιας μίσθωσης | Η μηχανή προτείνει σήμερα Airbnb **χωρίς να ξέρει αν επιτρέπεται** |

## Δεδομένα από οπουδήποτε — η πηγή `csv`

Οι πύλες είναι το εύθραυστο κομμάτι. Τίποτα κατάντη δεν εξαρτάται από αυτές:
η αποτίμηση, τα 32 πλάνα, οι έξι δείκτες και η δοκιμή αντοχής χρειάζονται μια
τιμή, ένα εμβαδόν και έναν τόπο. Δώστε τους ένα αρχείο και τρέχουν χωρίς δίκτυο.

Οι κεφαλίδες αναγνωρίζονται χαλαρά, στα ελληνικά ή στα αγγλικά, με «,», «;» ή tab:

| Χρειάζεται | Δέχεται |
|---|---|
| **τιμή** | Τιμή · Ζητούμενη τιμή · Τίμημα · price · asking |
| **εμβαδόν** | Εμβαδόν · τ.μ. · sqm · size · area |
| **περιοχή** | Περιοχή · Διεύθυνση · Δήμος · location · address |
| τύπος | Κατηγορία · type — «Μεζονέτα», «Οικόπεδο», «Κατάστημα», «Θέση στάθμευσης»… |
| έτος, lat/lng, url, περιγραφή | προαιρετικά |
| **ενοίκιο** | Ενοίκιο · Μίσθωμα — *ξεκλειδώνει όλα τα πλάνα εισοδήματος* |

Δύο λεπτομέρειες που κόστισαν από ένα σφάλμα η καθεμία: οι πίνακες συνωνύμων
κανονικοποιούνται όπως και οι κεφαλίδες, αλλιώς το τελικό σίγμα («Κωδικός» →
«κωδικοσ») εμποδίζει κάθε αντιστοίχιση· και ο έλεγχος τύπου γίνεται σε όρια
λέξης, γιατί το «warehouse» περιέχει «house» και καταχωρούνταν ως κατοικία.

## Ο κατάλογος μεσιτών

Πηγή: ο δημόσιος κατάλογος επαγγελματιών του xe.gr (`/property/pros`).

Παρατηρήθηκαν **5.070 προφίλ**, εκ των οποίων ~2.800 μεσιτικά γραφεία, και οι
υπόλοιποι εταιρείες διαχείρισης ακινήτων και κατασκευαστικές.

- **Email:** αντλείται αξιόπιστα από τη σελίδα προφίλ (σε δείγμα 14 προφίλ,
  14/14 είχαν email).
- **Τηλέφωνο:** *δεν* αντλείται. Το τηλέφωνο που εμφανίζεται στο υποσέλιδο κάθε
  προφίλ ανήκει στο ίδιο το xe.gr, όχι στον μεσίτη· το τηλέφωνο του γραφείου
  αποκαλύπτεται με JavaScript πίσω από κουμπί. Το πεδίο μένει κενό αντί να
  γεμίσει με λάθος αριθμό.
- **Αποδιπλασιασμός:** προφίλ που μοιράζονται email ή τηλέφωνο συγχωνεύονται —
  τα γραφεία καταχωρούν συχνά ένα προφίλ ανά υποκατάστημα.

Μια πλήρης σάρωση με `--with-contacts` είναι ~2.800 αιτήματα· στα 2 δευτερόλεπτα
ανά αίτημα, περίπου 1,5 ώρα. Είναι resumable χάρη στο cache.

## Η καμπάνια

Έξι σημεία, σε κάθε κανάλι:

1. Η Damasol Limited είναι **επενδυτικός οργανισμός**.
2. Απευθύνεται σε **επαγγελματίες ακινήτων σε όλη την Ελλάδα**.
3. Αν έχουν ακίνητο που **οι ίδιοι** θεωρούν πραγματική επαγγελματική ευκαιρία,
   να επικοινωνήσουν.
4. Να στείλουν τις **λεπτομέρειες** του ακινήτου.
5. Να εξηγήσουν **γιατί το θεωρούν ευκαιρία**.
6. Η Damasol είναι **ανοιχτή** και **έμπειρη** τόσο σε **προτάσεις συνεργασίας**
   όσο και σε **ευέλικτα επιχειρηματικά μοντέλα**.

Κανάλια: `email`, `email_en`, `follow_up`, `sms`, `viber`, `linkedin`,
`brief_form` (φόρμα υποβολής ακινήτου προς συμπλήρωση από τον μεσίτη).

```bash
python -c "from damasol.outreach import render; print(render('viber','ΑΒΓ Ακίνητα',{'reply_email':'deals@damasol.com'})['body'])"
```

### Αποστολή

Η αποστολή είναι **απενεργοποιημένη εξ ορισμού** και απαιτεί **δύο** ρητές
σημαίες (`--send --confirm-send`) συν διαπιστευτήρια SMTP από το περιβάλλον.
Κάθε αποστολή καταγράφεται σε `*.sent.csv`, το οποίο λειτουργεί αυτόματα ως
λίστα εξαίρεσης στην επόμενη εκτέλεση — κανείς δεν λαμβάνει δύο φορές.

**Διαβάστε το `outreach/COMPLIANCE_GDPR.md` πριν στείλετε το πρώτο μήνυμα.**
Ένα σημείο εκκρεμεί εξ ορισμού: ο σύνδεσμος πολιτικής απορρήτου που απαιτεί το
άρθρο 14 ΓΚΠΔ, επειδή εξαρτάται από τον ιστότοπό σας.
