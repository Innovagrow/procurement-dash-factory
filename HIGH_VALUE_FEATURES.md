## 1. 💰 BARGAIN DETECTOR (TOP PRIORITY)

### What It Does:
Identifies tenders priced BELOW market average - instant money-saving opportunities!

### Features:
- **Price Comparison Engine**
  - Compare tender value vs. historical average for same category
  - Show "% below market" indicator
  - Flag "HOT DEALS" (>20% below average)

- **Bargain Alert System**
  - Real-time notifications when bargains appear
  - Email + dashboard alerts
  - Customizable thresholds

### Example Display:
```
🔥 HOT DEAL ALERT!
IT Services Tender - Germany
€45,000 (38% BELOW market avg of €72,000)
Deadline: 14 days | Competition: Low (3 bidders)
[View Details] [Add to Watchlist]
```

## TECHNICAL NOTES

### Data Requirements:
- **Historical pricing data** - 12+ months for benchmarking
- **Competitor database** - Track suppliers & wins
- **User profiles** - Store preferences & history
- **Alert rules engine** - Real-time notifications

### APIs Needed:
- OpenAI/Claude for AI assistant
- Email service (SendGrid/AWS SES) for alerts
- Background job queue (Celery + Redis) for processing

### Database Schema:
```sql
-- Price benchmarks
CREATE TABLE price_benchmarks (
    category VARCHAR,
    country VARCHAR,
    avg_price DECIMAL,
    period DATE
);

-- User watchlist
CREATE TABLE watchlist (
    user_id INT,
    tender_id VARCHAR,
    added_date TIMESTAMP
);

-- Alerts
CREATE TABLE alerts (
    user_id INT,
    type VARCHAR,
    criteria JSONB,
    active BOOLEAN
);
```
